## 营养评级标准

### 单项营养素评级

| 评级 | 日均摄入占推荐量比例 | 含义 |
|---|---|---|
| 适中 | 80%-120% | 摄入量在合理范围 |
| 偏低 | < 80% | 摄入不足 |
| 偏高 | 120%-200% | 摄入过多 |
| 超标 | > 200% | 严重超标，需关注 |

### 综合营养结构评级

| 评级 | 标准 | 含义 |
|---|---|---|
| S | 各项均在适中范围，且能量来源比例合理 | 营养结构优秀 |
| A | 至多1项偏高/偏低，无超标项 | 营养结构良好 |
| B | 有1-2项偏高或超标 | 营养结构一般，建议调整 |
| C | 有多项超标，或钠/脂肪严重超标 | 营养结构需重点关注 |

## 计算方法

1. 从 order-list 获取评估区间内所有订单的餐品明细
2. 通过 list-nutrition-foods 匹配各餐品的营养成分
3. 按订单数量和时间跨度计算日均摄入量
4. 对照上表基准计算达标率
5. 按评级标准给出综合营养结构评级
