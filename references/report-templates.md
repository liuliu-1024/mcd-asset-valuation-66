# 评估报告模板骨架

> 本文件按需加载，为报告生成阶段提供各章节的详细模板。

## 报告封面

```
# 麦麦资产评估报告

**报告编号**：MCD-VAL-{YYYYMMDD}-{序号}
**评估基准日**：{YYYY-MM-DD}
**评估目的**：对评估对象的麦当劳消费资产价值进行评定估算
**价值类型**：市场价值
**评估方法**：市场比较法、重置成本法、收益现值法
**评估师**：执业资产评估师 x 房地产估价师
```

## 第三章：消费资产评估——市场比较法

```
## 三、消费资产评估——市场比较法

### 3.1 比较基准选取

比较基准为麦当劳官方菜单挂牌价，通过 query-meals 工具获取评估基准日有效价格。

### 3.2 各项修正

- 时间修正：评估区间内价格无显著变动，修正系数 1.00
- 规格修正：套餐已折算为等价单品组合，修正系数 1.00
- 促销修正：会员价/活动价差异已反映在实付金额中

### 3.3 评估结论

消费性价比系数：{coefficient}
性价比评级：{grade}级（{grade_description}）
```

## 第九章：评估假设与限制条件

```
## 九、评估假设与限制条件

1. 公开市场假设：评估基于麦当劳官方菜单公开标价，假设该价格在评估基准日有效。
2. 持续使用假设：假设用户将继续在麦当劳消费，积分账户持续有效。
3. 数据完整性假设：评估基于麦当劳 MCP 返回的数据，假设数据真实完整。
4. 积分政策不变假设：假设评估期内积分规则与兑换比例不发生重大变化。
5. 限制条件：本报告为趣味消费分析，不构成投资建议、资产证明或健康诊断。
```
