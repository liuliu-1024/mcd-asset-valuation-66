# 三大评估方法论详解

> 本文件按需加载，为 SKILL.md 的评估方法论提供详细计算公式与实操指引。

## 一、市场比较法（消费资产评估）

### 适用条件
- 评估对象：用户历史订单的实际成交组合
- 必须存在活跃的公开市场定价（菜单挂牌价）作为比较基准

### 计算步骤

1. **选取比较基准**：通过 `query-meals` 获取当前菜单挂牌价
2. **建立比较因素修正体系**：

| 修正因素 | 修正方法 | 数据来源 |
|---|---|---|
| 时间修正 | 远期订单参考当时价格，近期订单用当前价格 | order-list 的下单时间 |
| 规格修正 | 套餐拆解为单品后分别比价，或单品组合折算为套餐 | query-meal-detail |
| 促销修正 | 活动价/会员价与挂牌价的差异 | order-list 的实付金额 |

3. **计算修正后基准价**：修正后基准价 = 挂牌价 x 时间修正系数 x 规格修正系数 x 促销修正系数
4. **计算消费溢价率**：消费溢价率 = (实际支付 - 修正后基准价) / 修正后基准价
5. **性价比评级**：

| 评级 | 溢价率范围 | 含义 |
|---|---|---|
| S | < -20% | 极高性价比，优惠券使用优秀 |
| A | -20% ~ -10% | 高性价比，消费策略合理 |
| B | -10% ~ 0% | 中等性价比，有优化空间 |
| C | > 0% | 低性价比，实际支付超过挂牌价 |

### 评估结论模板
> 经市场比较法评定，评估对象在评估基准日的消费性价比系数为 X.XXX，属"XX性价比消费群体"，评级为 X 级。

## 二、重置成本法（优惠资产评估）

### 适用条件
- 评估对象：优惠券为用户带来的节约价值
- 重置全价可通过 `calculate-price` 获取当前菜单价格计算

### 计算步骤

1. **计算重置全价**：重置全价 = Σ(用户消费过的各餐品 x 当前挂牌单价)
2. **计算实际支付**：实际支付 = Σ(历史订单实付金额)
3. **计算优惠券节约净值**：节约净值 = 重置全价 - 实际支付
4. **计算闲置券减值**：
   - 已领未用的优惠券：闲置贬值 = 优惠券面值 x 闲置天数 / 有效期天数
   - 即将过期的优惠券：减值准备 = 优惠券面值（全额计提）
5. **计算重置净值**：重置净值 = 节约净值 - 闲置贬值 - 减值准备
6. **优惠券利用率评级**：

| 评级 | 利用率范围 | 含义 |
|---|---|---|
| S | > 95% | 优惠券管理优秀 |
| A | 80% ~ 95% | 优惠券管理良好 |
| B | 60% ~ 80% | 优惠券管理一般 |
| C | < 60% | 优惠券管理不足 |

### 评估结论模板
> 经重置成本法评定，评估对象在评估基准日的优惠资产重置全价为 ¥X,XXX.XX，优惠券节约净值为 ¥XXX.XX，闲置券减值为 ¥XX.XX，优惠券利用率为 XX.X%，评级为 X 级。

## 三、收益现值法（积分资产评估）

### 适用条件
- 评估对象：用户积分账户中的可用积分
- 需有历史消费数据预测未来积分收益流
- 需有积分商城数据确定积分变现单价

### 计算步骤

1. **确定积分账户现状**（`query-my-account`）：
   - 可用积分、累计积分、冻结积分、即将过期积分

2. **确定积分变现单价**（`mall-points-products`）：
   - 单积分变现价值 = 商城商品现金价值 / 所需积分
   - 取多个商品的平均值作为基准变现单价

3. **预测未来收益流**：
   - 历史月均消费积分增量 = 评估区间累计积分 / 评估月数
   - 未来月均预期积分 = max(历史月均, 近3月月均)

4. **确定折现率**：
   - 基准折现率 = 8%（含积分通胀率 + 机会成本）
   - 如积分商城兑换比例下降，上调折现率

5. **计算评估现值**：
   - 预测期 N = 12 个月（默认）
   - 积分资产现值 = Σ(t=1 to N) [月均预期积分 / (1+折现率)^(t/12)] x 变现单价
   - 简化计算（等额年金）：现值 ≈ 月均预期积分 x 12 x 变现单价 / (1 + 折现率/2)

6. **减值测试**：
   - 即将过期积分减值准备 = 即将过期积分 x 变现单价
   - 冻结积分：视冻结原因决定是否计提减值
   - 积分资产评估净值 = 积分资产现值 - 减值准备

### 评估结论模板
> 经收益现值法评定，评估对象在评估基准日的积分账户可用积分为 X,XXX 分，按变现单价 ¥0.00X/分计算，预测期 12 个月，折现率 8%，积分资产评估现值为 ¥X,XXX.XX。其中即将过期积分 XXX 分，计提减值准备 ¥XX.XX，积分资产评估净值为 ¥X,XXX.XX。
